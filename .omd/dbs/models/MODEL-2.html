MODEL-2

Task execution

summary
How plans turn into ordered, non-conflicting units of work.

Intent

A plan authorizes a graph of tasks. Work starts only when dependencies are ready and ownership boundaries do not collide.

Rules

1. Tasks inherit intent from one plan. 2. Dependencies must be complete before a task becomes active. 3. Overlapping ownership boundaries must not run at the same time. 4. Review of the project’s approved snapshot decides what agents may trust as current execution state.
