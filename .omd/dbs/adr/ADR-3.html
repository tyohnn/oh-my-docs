ADR-3

Fumadocs as the SSOT renderer

stage
accepted
summary
One MDX collection → browser pages and agent Markdown (local SSOT).

Context

Handbook must serve people (navigable site) and agents (Markdown).

Decision

Use one Fumadocs MDX collection as the local renderer for /docs and /md twins.

Note

Applies when ssot: local. Notion SSOT does not use Fumadocs as content authority.
