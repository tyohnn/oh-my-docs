ADR-2

Select one content source per project

stage
accepted
summary
Exactly one SSOT per project; ports + MCP isolate providers.

Context

Projects need one authoritative handbook store; provider details should stay behind ports.

Decision

Exactly one SSOT per project: local \| notion (set reduced by ADR-008). Runtime manifests + host MCP isolate provider details.

Consequences

Unselected providers are not truth. Ask SSOT before first adopt.
