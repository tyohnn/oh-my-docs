POLICY-1

Single content source

summary
A project has exactly one handbook authority; never two.

Policy

A project has exactly one handbook content source.

  • Do not treat an unselected store as truth.
  • Do not keep two sources “both authoritative.”
  • If an old unsupported source appears in project config, switch to local or Notion and stop using the old one.
