TERM-4

Provisioning manifest

summary
A planned, ordered set of content-source setup steps the host carries out.

Meaning

A provisioning manifest is the ordered plan for setting up or repairing a content source layout (Home, catalogs, relations). The skill decides *what* should exist; the host environment applies the steps. The manifest is an operational handoff, not a product requirement document.
