TERM-3

Provider mapping

summary
Recorded links between stable handbook keys and objects in the chosen content source.

Meaning

A provider mapping remembers which object in the content source corresponds to which stable handbook key (for example Home, PRDs catalog, Plans catalog). Mappings make adopt and sync idempotent: agents can re-run without inventing duplicate catalogs. They are bookkeeping for the port, not product requirements.
