US-12

Author wireframes from a shared structural kit

summary
As an agent filling a layout or screen-state, I use the same chrome and block kit so mocks stay comparable across projects.
PRD
PRD-7
Features

Persona

Coding agent (or human) authoring LAY-* / STA-* HTML in a host repo.

Narrative

I keep the template device chrome, label regions with product roles, and reuse the shared omd-wire-* blocks. Mobile and desktop show the same regions. I do not invent a custom visual language, dump lorem, or pixel-paint the UI.

Acceptance

  • references/wireframe-authoring.md is the authoring SSOT; SKILL.md points to it.
  • Templates demonstrate the kit (device chrome + named blocks + one primary).
  • omd check requires matching device wrappers and at least one kit block per viewport.
