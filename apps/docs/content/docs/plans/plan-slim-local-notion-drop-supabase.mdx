## Scope

1. Runtime/contract: `contentSource.ssot` ∈ {`local`,`notion`} only; reject
   `supabase` on adopt/check/new.
2. Notion: slim IA graph (Home + inline catalog DBs). Remove Vision / Start
   here / Workflow from Notion provision.
3. Local: keep full Fumadocs MDX handbook IA.
4. Delete Supabase content-port adapters, remote loaders, ISR/revalidate API,
   notify helpers, and Vercel content-port ops from skills/docs app.
5. **Remove planning/development gates:** delete or no-op
   `scripts/check-docs-first.mjs` / `pnpm check:docs-first`; strip CI steps;
   rewrite `SKILL.md`, markers, root `AGENTS.md` / `CLAUDE.md` so agents do not
   block on PRD/story/SPEC/PLAN or `Plan:` trailers. Keep optional
   `check:planning` and `omd new` for voluntary catalog hygiene.
6. Dogfood: `.omd` → `ssot: local`.
7. `pnpm sync:skills`.

Out of scope: auto-export Supabase rows to Notion; redesigning local Vision
pages; building a replacement human task product.

## Implementation sequence

1. Land this ready plan (docs-only) on `main`.
2. Remove docs-first gate script + package script + CI + skill/AGENTS language.
3. Slim Notion IA + wire adopt/check; keep full graph for local.
4. Remove supabase branches and apps/docs remote/revalidate path.
5. Migrate dogfood `.omd` to local; refresh markers.
6. Tests + `pnpm check:skills` (+ optional `check:planning`).

## Verification

- `adopt --ssot supabase` fails; `needsSsot` is `local` | `notion`.
- Notion dry-run: catalog DBs only (no Vision/Workflow).
- Local docs build without Supabase env; no `/api/revalidate`.
- `pnpm check:docs-first` absent or exits 0 with a retired message; skill text
  does not instruct agents to refuse code without a ready plan.
- `pnpm check:skills`; relevant unit tests pass; dogfood `ssot: local`.

## Migration and compatibility

- Superseded: ADR-006/007, SPEC-010–012, PLAN-014–017, PRD-006/007 (done).
- Docs-first merge policy retired via amended `SPEC-docs-first-development`.
- Adopters on supabase re-adopt or edit `.omd` to `local`|`notion`.

## Risks and rollback

- Teams that relied on the gate lose CI enforcement — intentional.
- Pull Supabase → local MDX once before cutting remote serve if needed.
- Rollback: revert implementation PR.
