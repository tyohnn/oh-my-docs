## Scope

Hard delete / hard cut — **no** no-op shims, dual-read, or soft migration.

1. Contract/runtime: only `local` | `notion`. Reject `supabase` everywhere.
2. Notion: slim IA (Home + inline catalog DBs). No Vision / Workflow pages.
3. Local: keep full Fumadocs MDX IA.
4. **Delete** Supabase adapters, SQL templates, remote loaders, pull/push
   authority path, revalidate API, notify/revalidate-env, Vercel content-port
   ops, and Supabase-only handbook catalog pages (PRD/ADR/SPEC/PLAN/US/glossary
   stubs that exist only for that path).
5. **Delete** `scripts/check-docs-first.mjs`, `pnpm check:docs-first`, CI wiring,
   and all agent/AGENTS language that blocks on plans. Not a no-op.
6. Dogfood: set `.omd` to `ssot: local` in the same change. No export pipeline
   from Supabase.
7. `pnpm sync:skills`.

Out of scope: rebuilding a human task product; Notion↔local sync.

## Implementation sequence

1. Land this plan on `main` (docs-only).
2. Delete docs-first gate + skill/AGENTS gate language.
3. Slim Notion IA; remove supabase from runtime/schemas/tests.
4. Delete apps/docs Supabase serve + revalidate + dead scripts/env keys.
5. Delete retired Supabase catalog docs from `content/docs` + meta.json.
6. Point dogfood `.omd` at local; sync markers.
7. `pnpm check:skills` + unit tests.
