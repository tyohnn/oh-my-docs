## Meaning

A **content port** is the provider-neutral interface through which the skill
inspects, provisions, creates, validates, and records handbook content.

The local adapter uses the filesystem. The Notion adapter plans deterministic
MCP operations which the invoking agent executes. A former Supabase adapter is
retired (`ADR-008`).
