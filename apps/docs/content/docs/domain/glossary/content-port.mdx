## Meaning

A **content port** is the provider-neutral interface through which the skill
inspects, provisions, creates, validates, and records handbook content.

The local adapter implements the port with filesystem operations. The Notion
adapter plans deterministic MCP operations which the invoking agent executes.
The Supabase adapter plans deterministic SQL/seed and document manifests which
the host Supabase CLI or MCP applies; Fumadocs reads the remote store.
