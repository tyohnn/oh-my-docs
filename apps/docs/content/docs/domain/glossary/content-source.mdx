## Meaning

A **content source** is the single authoritative store for handbook artifacts
in one adopted repository.

Supported values:

- `local`: MDX under the configured docs content path
- `notion`: pages and databases beneath one configured Notion root page

Generated state, caches, previews, and provider mappings are not additional
content sources.
