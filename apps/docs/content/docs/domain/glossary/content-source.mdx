## Meaning

A **content source** is the single authoritative store for handbook artifacts
in one adopted repository.

Supported values:

- `local`: MDX under the configured docs content path (full Fumadocs IA)
- `notion`: inline catalog databases beneath one configured Notion Home page

`supabase` is not supported (`ADR-008`).
