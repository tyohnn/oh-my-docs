## Meaning

A **provisioning manifest** is an ordered set of create, update, skip, relation,
or archive operations produced from the `.omd` contract, skill **`references`**
templates, and current provider snapshot.

Every operation declares a stable OMD key, expected parent, dependencies, and
desired schema. It contains no credentials.

For Notion, default IA and page-chrome templates live under
`skills/oh-my-doc/references/` (not a `ref/` path and not Notion HTML export).
