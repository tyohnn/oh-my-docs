## Status

**Superseded.** `contentSource.ssot: supabase` is no longer a product option.
Kept as a glossary stub so older ADRs/PRDs remain readable.

## Historical meaning

A **Supabase handbook** was a `handbookId` namespace inside a user-owned
Supabase `projectRef` when that SSOT was offered (PRD-006 / ADR-006). Shipping
SSOT choices are now only `local` and `notion`.
