## Rule

A repository selects exactly one handbook content source in
`.omd/project.json`: `local` or `notion`.

## Consequences

- Skills reject operations that would write to an unselected provider.
- Notion projects do not create an editable MDX mirror.
- Local projects do not treat a provisioned Notion workspace as current truth
  unless selected.
- Switching providers requires a separately confirmed migration.
- `supabase` is not a valid selection (`ADR-008`).
