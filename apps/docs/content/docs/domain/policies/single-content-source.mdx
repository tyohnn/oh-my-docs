## Rule

A repository selects exactly one handbook content source in
`.omd/project.json`: `local`, `notion`, or `supabase`.

## Consequences

- Skills reject operations that would write to an unselected provider.
- Notion projects do not create an editable MDX mirror in v1.
- Supabase projects do not treat a Git MDX tree as authoritative.
- Local projects do not treat a provisioned Notion or Supabase store as
  current truth unless selected.
- Switching providers requires a separately confirmed migration plan.
