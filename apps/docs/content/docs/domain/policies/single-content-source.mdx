## Rule

A repository selects exactly one handbook content source in
`.omd/project.json`: `local` or `notion`.

## Consequences

- Skills reject operations that would write to the unselected provider.
- Notion projects do not create an editable MDX mirror in v1.
- Local projects do not treat a provisioned Notion workspace as current truth.
- Switching providers requires a separately confirmed migration plan.
