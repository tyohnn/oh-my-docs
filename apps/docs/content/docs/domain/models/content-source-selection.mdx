## Model

```text
Project contract
  ├── selects exactly one Content source
  ├── configures one Content port adapter
  └── produces Provider mappings in operational state
```

The project contract stores non-secret source identity and configuration.
Operational state stores generated object IDs, schema digests, and observation
timestamps. Credentials remain with the host integration.

## Invariants

- One project has exactly one authoritative source.
- Local and Notion adapters expose equivalent planning operations.
- Provider mappings can be discarded and reconstructed.
- Changing source is an explicit migration, never an implicit sync.
