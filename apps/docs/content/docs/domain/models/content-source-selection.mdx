## Model

```text
Project contract
  ├── selects exactly one Content source (local | notion)
  ├── configures one Content port adapter
  └── produces Provider mappings in operational state (notion)
```

The project contract stores non-secret source identity. Operational state
stores generated object IDs and observation timestamps. Credentials remain
with the host integration (e.g. Notion MCP).

## Invariants

- One project has exactly one authoritative source (`local` or `notion`).
- Local and Notion adapters expose equivalent planning operations where
  applicable.
- Provider mappings can be discarded and reconstructed.
- Changing source is an explicit migration, never an implicit sync.
- `supabase` is invalid on new contracts (`ADR-008`).
