## Content source

Read `.omd/project.json` `contentSource.ssot`:

- **`local`** — this Fumadocs MDX tree
- **`notion`** — one Home page with inline catalog databases only

There is no `supabase` SSOT.

## Work style

1. Implement when the change is clear — **no** required PRD → SPEC → ready plan
   chain and no `Plan:` trailer (`ADR-008`).
2. If a decision should survive chat, add or update a catalog row (ADR, data /
   API spec, etc.) via `omd new` or the Notion DB.
3. Optional hygiene: `pnpm check:planning` when you care about IDs/nav.

See [planning](/docs/workflow/planning) and
[development](/docs/workflow/development). Agents use the
[skill runtime](/docs/spec/system-model/cli).
