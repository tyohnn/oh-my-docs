## Intent

PRD / story / SPEC / ADR / plan pages are ordinary handbook catalogs. Use them
when useful. They are not a required sequence before code.

Read `.omd/project.json` `contentSource.ssot` (`local` | `notion`) before
editing handbook content.

## Local vs Notion

- **Local:** full Fumadocs tree in this repo
- **Notion:** Home + inline catalog DBs only

## Creating entries

```bash
node <skill>/scripts/omd.mjs new prd|story|spec|plan|adr --title "…" --yes
```

Prefer updating a stable ID over duplicating. There is no docs-first CI gate.
