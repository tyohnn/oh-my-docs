## Scope

Defines how implementation relates to handbook artifacts after `ADR-008` /
`PRD-008`. There is **no** machine-enforced docs-first gate.

## No mandatory gate

- Pull requests do **not** require a `Plan: …` trailer.
- Product, bugfix, and maintenance code may land without a prior ready plan
  on the base branch.
- `pnpm check:docs-first` is removed (or becomes a no-op that always passes).
- Agents must not block on missing PRD / story / SPEC / PLAN before coding.

## Optional durable memory

When a decision should outlive chat, agents **may** write or update catalog
rows (local MDX or Notion inline DB)—ADR, Data model, API/system spec, plan
notes, etc. That is recommended for cold-start agents, not a merge
requirement.

`pnpm check:planning` may remain as an **optional** integrity check for
handbook IDs/navigation when catalogs exist; it is not a development gate.

## Completion

Mark catalog plans `done` only if the team still uses them; otherwise leave
or delete. Reviewers remain responsible for product correctness.
