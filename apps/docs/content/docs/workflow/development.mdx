## Contract

There is no planning/development gate.

- No `Plan:` trailer
- No ready plan on the PR base
- No `check:docs-first` (script removed)
- Agents do not refuse code for missing PRD / story / SPEC / PLAN

Write catalog pages only when you want durable notes in the handbook. That is
normal documentation, not a merge prerequisite.
